# Baby Name Generator 👶

A simple Python application that generates baby name suggestions based on the child's gender and the user's family name.

## ✨ Features

- Generate 50 baby name suggestions.
- Support for male and female names.
- Customize suggestions using the user's family name.
- Simple and interactive command-line interface.
- Uses the Faker library to generate names.

## 🛠️ Technologies Used

- Python
- Faker

## 🚀 Installation & Usage

**1. Clone the repository**

```bash
git clone https://github.com/tamar77623/Baby-Name-Generator.git
```

**2. Navigate to the project directory**

```bash
cd Baby-Name-Generator
```

**3. Install the required library**

```bash
pip install Faker
```

**4. Run the application**

```bash
python main.py
```

## 🎯 How It Works

1. Enter your family name.
2. Choose the baby's gender (Boy or Girl).
3. The application generates 50 name suggestions.
4. Explore the generated names!
